Deze module is ontwikkeld voor erfgoedvrijwilligers en professionals die gegevens verzamelen over bouwhistorische objecten. 
Goede dataorganisatie is belangrijk voor een goede basis van elk project. 
Een spreadsheet (bv. een Excel-bestand) is een goede manier om data in op te slaan, maar heeft ook zijn beperkingen.
Deze module laat je in korte tijd de meerwaarde zien van het gebruik van een relationeel model en laat je proeven aan de kracht van database-gebruik.

De module is echt bedoeld als **inzicht geven in** het relationele model en gebruik van databases,
**specifiek niet het aanleren van vaardigheden om met databases om te gaan**.
In het laatste hoofdstuk geven we de volgende stappen aan om die vaardigheden echt te leren.
Het idee van deze aanpak is dat het nuttig is wanneer je data verzameld in een spreadsheet om alvast een beeld te hebben 
van hoe de data uiteindelijk terecht kan komen in een database.

## Historisch glas
In deze module staat historisch glas centraal. Veel historische gebouwen bevatten uiteenlopende soorten glas, zoals glas in lood ramen in monumentale kerken of draadglas in bijvoorbeeld monumentale schoolgebouwen uit de jaren 1950. Er bestaat nog geen doorzoekbaar, volledig overzicht van welke bouwhistorisch relevante gebouwen welke typen glas bevatten, maar er is wel behoefte aan. Vanuit verschillende kanten worden hier initiatieven op vormgegeven.

We raden aan deze module te volgen na de module [Dataorganisatie in spreadsheets voor bouwhistorie](https://digitaal-erfgoed-trainingen.github.io/Dataorganisatie_spreadsheets_bouwhistorie/), 
maar de module kan ook op zichzelf gevolgd worden als de cursist bekend is met dataorganisatie in spreadsheets.

## Doelgroep
De cursus is bedoeld als basiscursus voor iedereen die met tabulaire data werkt. De casuïstiek is weliswaar glas voor bouwhistorie, maar de lessen zijn ook bruikbaar voor andere (sub)domeinen. 

## Leerdoelen
Na afloop van deze module kan de deelnemer:

* Uitleggen wat de meerwaarde van een relationeel datamodel is
* Begrijpen hoe je spreadsheet data kunt omzetten naar een relationeel model
* De kracht van databases inzien
* De volgende stappen kennen om te leren hoe je een relationele database gebruikt
